# 截图

都是模拟器上 `adb exec-out screencap` 直接抓的原图，没修、没拼。机器是 Android 16，1080×2400。旧图（OSM 栅格时代、还有开屏 Q 图的那批）已经删了，留着只会误导人。

## 现在这版

首页。底图是 OpenFreeMap 的 positron，干净得有点过分，震中按震级上色：

![首页](https://aka.doubaocdn.com/s/qib1sLwVZD)

点一下震中圆点，弹出详情：震级、深度、时间、PAGER、海啸评估、事件 ID。这个是日本 Tateyama 附近的 M5.2：

![点震中出详情](https://aka.doubaocdn.com/s/TAES3qdXYf)

冷启动。开屏图删了，就剩浅灰底加系统自己的加载环，没有那个一闪而过的 Q：

![冷启动](https://aka.doubaocdn.com/s/JtcazHRadH)
